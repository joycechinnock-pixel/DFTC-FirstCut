# Setup guide

## Getting started

This repo is the portfolio and launch hub for the FirstCut series.

Use it as the top-level navigation layer for the ecosystem, and then move into the app-specific files for more detailed work.

---

## Recommended workflow

1. Start at the [landing page](../README.md)
2. Choose the app you want to explore or build
3. Open the relevant app document in [docs/apps](apps)
4. Move into deeper strategy or implementation work as required

---

## Local repo workflow

```bash
git clone https://github.com/joycechinnock-pixel/DFTC-FirstCut.git
cd DFTC-FirstCut
```

Then create a new feature branch:

```bash
git checkout -b feature/your-area
```

---

## Repo structure

- `README.md` — landing page and entry portal
- `docs/` — mission, roadmap, metrics and guidance
- `docs/apps/` — app-specific summary pages
- `docs/dev/` — developer setup and workflow docs
- `docs/community/` — user and contributor guidance
- `docs/investors/` — portfolio overview and partnership materials

---

## Keep it simple

This repo is the narrative and navigation layer. Product implementation work may live elsewhere if needed, but the hub remains the single source of portfolio clarity.
