# Portfolio metrics

## Key measures of success

The FirstCut ecosystem should be evaluated as one portfolio, not just as five separate apps.

---

## User and audience metrics

- total active users across the portfolio
- conversion rate from visitor to sign-up
- user retention by app
- traffic quality and acquisition efficiency
- cross-app engagement and discovery

## Experience and trust metrics

- time on task
- activation rate
- user satisfaction and qualitative feedback
- UI completion and issue resolution rate
- reduction in UX friction and support burden

## Commerce and monetisation metrics

- conversion from traffic to purchase
- product catalog engagement
- cart completion and repeat purchase rate
- average order value
- revenue quality and operating margin

## Impact and community metrics

- community participation rate
- support pathway completion
- referral and trust-building outcomes
- benefit delivered to vulnerable users
- user stories and real-world case outcomes

## Operational utility metrics

- workflow time saved for businesses
- quote-to-close conversion
- invoicing and admin completion rate
- lower paperwork burden and reduced missed tasks
- task resolution speed

---

## Primary portfolio objective

The portfolio succeeds when each app contributes to a wider loop:

user growth -> trust -> value -> impact -> utility -> return
