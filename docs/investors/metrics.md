# Investor metrics

## Portfolio traction framework

This section is intended to summarise the important metrics behind the FirstCut strategy.

---

## Core portfolio metrics

- user growth and activation
- user retention and trust signals
- conversion from interest to value
- revenue generation potential
- real-world utility and operational impact

---

## Portfolio logic

A portfolio works best when multiple products reinforce each other and reduce waste across strategy, growth and launch planning.

The portfolio is designed to create value on several fronts at once: audience, trust, revenue and impact.
