# FAQ

## Frequently asked questions

### Why are the apps linked together?
Because the portfolio is designed to compound growth, trust, value and community impact. Each app supports the others.

### Are these apps all being built at once?
Not in the same intensity. The portfolio is staged so that early traction and trust support later expansion.

### Which app should I start with?
Start with the area that matches your interest or need. If you are focused on growth, MintWall is the entry point. If you are exploring commerce, start with DFTC.

### Is this just a tech project?
No. It is a portfolio with product, community and business logic built into it.

### What is the long-term aspiration?
To build a resilient ecosystem that delivers real-world value for people, communities and businesses over time.
